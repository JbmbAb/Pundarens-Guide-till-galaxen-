# Pundarens vän till galaxen (Stoner's Friend to the Galaxy) - Updated Brief ## 🎯 Overall Vision An illogical yet indispensable digital companion inspired by *The Hitchhiker's Guide to the Galaxy*. It's a map, a philosopher, and a late-night snack guide rolled into one. ## 🚀 Key Features * **"Don't Panic" Wisdom Generator:** A central, pulsating button delivering random, profound, and nonsensical advice. * **Cosmic Navigator (GIS Support):** An interactive map for essential intergalactic locations like rest areas, public toilets, and late-night snack spots (munchie stations). * **Babel-Stoner Translator:** Translates standard text into abstract, rhythmic intergalactic slang. * **Infinite Improbability Theme Engine:** A Material 3 UI that shifts appearance based on "probability drives." * **Towel Tracker (Handdukssensorn):** Uses gyroscopes to "detect" your towel. Shake to unlock cosmic easter eggs. * **Vibe Protect (Vogon-poesi-blockerare):** A specialized "Do Not Disturb" mode to silence unwanted "alien" calls (bosses, telemarketers). ## ⚙️ Technical Stack * **Kotlin & Jetpack Compose:** Modern, reactive UI with Material 3. * **Google Maps SDK:** Custom GIS visualizations. * **Kotlin Coroutines:** Async task management. * **KSP & Moshi:** High-performance data parsing. * **Coil:** Vibrant image loading. * **Room Database:** Local caching for offline "munchie" mapping. * **Retrofit:** Dynamic API fetching for fresh wisdom and slang.
