# Pundarens vän till galaxen (Stoner's Friend to the Galaxy) ## Project Overview A digital companion inspired by *The Hitchhiker's Guide to the Galaxy*, designed to be illogical yet indispensable. It features a vibrant, energetic Material 3 aesthetic with cosmic guidance for the modern wanderer. ## Key Features * **"Don't Panic" Wisdom Generator:** A central, pulsating button delivering random, profound, and nonsensical advice. * **Cosmic Navigator (GIS Support):** An interactive map for essential intergalactic locations like rest areas, public toilets, and late-night snack spots (munchie stations). * **Babel-Stoner Translator:** Translates standard text into abstract, rhythmic intergalactic slang. * **Infinite Improbability Theme Engine:** A Material 3 UI that shifts appearance based on "probability drives" using dynamic color and motion. ## Technical Stack * **Language:** Kotlin * **UI Framework:** Jetpack Compose (Material 3, Edge-to-edge, Animations) * **Maps:** Google Maps SDK for Android * **Asynchronous Logic:** Kotlin Coroutines * **Processing/Parsing:** KSP & Moshi * **Image Loading:** Coil
